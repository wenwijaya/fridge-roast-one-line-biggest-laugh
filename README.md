A one-line roast of a smart fridge, written by a program for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty. The program writes a single line — the fridge snitching on the milk through its app, while keeping that milk cold was its one job — to `/output/entry.txt`, 93 characters, one line, nothing else.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt`: one line, one roast.
